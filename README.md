## 🤖 Mini Meta-Agent — Multi-Agent Mathematical Reasoning System

> **Multi-Agent AI + RAG + Automated Debate + LLM Orchestration**

A multi-agent mathematical reasoning system designed to solve word problems through **independent reasoning, verification, debate, and final judgment**.

### Architecture

```text
                 ┌──────────────────────┐
                 │     Math Problem     │
                 └──────────┬───────────┘
                            │
                            ▼
                 ┌──────────────────────┐
                 │   Context Manager    │
                 └──────────┬───────────┘
                            │
                            ▼
                 ┌──────────────────────┐
                 │   RAG / FAISS Search │
                 └──────────┬───────────┘
                            │
              ┌─────────────┼─────────────┐
              ▼             ▼             ▼
        ┌──────────┐  ┌──────────┐  ┌──────────┐
        │ Solver 1 │  │ Solver 2 │  │ Solver 3 │
        │Analytical│  │ Creative │  │Verifier  │
        └────┬─────┘  └────┬─────┘  └────┬─────┘
             │             │             │
             └─────────────┼─────────────┘
                           ▼
                  ┌──────────────────┐
                  │   Debate / Judge │
                  └────────┬─────────┘
                           ▼
                  ┌──────────────────┐
                  │ Verified Answer  │
                  └──────────────────┘
```

### Core Components

- Multi-agent mathematical reasoning
- Analytical, creative and verification agents
- Automated agent debate
- Judge agent for answer selection
- Reflection mechanism
- Planner agent
- Context management
- RAG-based mathematical knowledge retrieval
- FAISS vector search
- BGE / Sentence Transformer embeddings
- LLM provider routing

### Data Sources

`Math23K` • `MAWPS` • `GSM8K`

### Stack

`Python` `Flask` `PostgreSQL` `FAISS` `Sentence Transformers`  
`Gemini` `Groq` `Cohere` `Hugging Face`

I generally think of an AI application as more than just a trained model.

```text
                 ┌───────────────────────┐
                 │      Problem          │
                 └───────────┬───────────┘
                             │
                             ▼
                 ┌───────────────────────┐
                 │ Data / Documents      │
                 └───────────┬───────────┘
                             │
                             ▼
                 ┌───────────────────────┐

                 ┌───────────────────────┐
                 │ ML / DL / LLM Layer   │

                             │
                             ▼
```
